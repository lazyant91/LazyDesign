> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce a new six-cell schema-2 LazyDesign evaluation whose experimental inputs match r2 while controller-authored RUN metadata is fixed before capture, so aggregate validation can classify execution readiness without a metadata-drift failure.

**Architecture:** Reuse the existing schema-2 `controller-reconciled-v1` harness and the exact r2 matrix contents. Add no new evaluation runtime or schema. The controller writes a fixed set of common RUN fields for every cell and runs an inline pre-capture metadata guard before each immutable capture.

**Tech Stack:** Python 3 evaluation harness, PowerShell/Remote controller, .NET SDK 9.0.313, Windows App SDK 2.0.1, Windows UI Automation, Git.
