# Component references

Component pages document the basic visual and interaction contract of a control that has already been selected by the product requirement or existing code.

They do not choose between unrelated controls, design a screen flow, or introduce a wrapper control. Each page must follow `docs/templates/component-reference.md`, cite source IDs from `sources/manifest.yaml`, and distinguish requirement level from evidence type.

- `button.md`
- `textbox.md`

A page becomes active only after its source evidence, minimal native XAML, checklist, and cross-page review are complete.
