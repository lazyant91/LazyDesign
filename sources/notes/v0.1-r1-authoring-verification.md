# v0.1-r1 authoring verification

## Scope

This note records source research and compile checks for the three reference revisions prompted by the first controlled v0.1 evaluation. These checks validate reference examples only. They are not scored model-run evidence and do not alter the original captured evaluation.

## Source review

- Retrieval date: 2026-08-07.
- `MS-WIN-XBIND`: Microsoft Learn `{x:Bind}` page, last updated 2026-07-15. It documents compile-time generated binding code, compile-time validation, and typed `DataTemplate` use with `x:DataType`.
- Windows data-binding-in-depth page: reviewed 2026-08-07, last updated 2026-07-15, as corroborating context for WinUI 3 compiled binding behavior. No new manifest ID was needed for the targeted rule.
- `MS-DOTNET-WINRT-AWAIT`: Microsoft Learn `System.WindowsRuntimeSystemExtensions.GetAwaiter` API, retrieved 2026-08-07. The API is in namespace `System`, includes `GetAwaiter<TResult>(IAsyncOperation<TResult>)`, and supports compiler `await` over Windows Runtime async operations.
- Existing `MS-WIN-CONTROLS-DIALOGS`: rechecked 2026-08-07; the current page was last updated 2026-07-15 and shows `ShowAsync()` plus the WinUI 3 `XamlRoot` requirement.
- Existing `MS-WIN-CONTROLS-INFOBAR`: rechecked 2026-08-07; the current page was last updated 2026-02-25 and its `ActionButton` examples wire `Click` handlers.
- Existing `MS-WIN-KEYBOARD-INTERACTIONS`: rechecked 2026-08-07; the current page was last updated 2026-03-05 and requires keyboard navigation/activation access to app functionality.
